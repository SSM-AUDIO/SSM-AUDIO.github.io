Install Best Limiter 3 on macOS

  1. Close your DAW. Download the Best Limiter 3 package from the download page and open it.
  2. If macOS blocks the installer, open System Settings → Privacy & Security and choose Open Anyway for this package.
  3. Complete the installation. Reopen your DAW and rescan VST3 plugins.

Установка на macOS

  1. Закройте DAW. Скачайте пакет Best Limiter 3 со страницы загрузки и откройте его.
  2. Если macOS заблокирует установщик, откройте Системные настройки → Конфиденциальность и безопасность и выберите Всё равно открыть для этого пакета.
  3. Завершите установку. Откройте DAW и пересканируйте плагины VST3.
